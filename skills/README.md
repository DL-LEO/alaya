# Alaya 子技能

| 子技能 | 负责什么 | 常见触发 |
|---|---|---|
| `alaya-persona` | 角色使用、复制、回收、群组讨论、统一语言 | “用费曼回答”“让几个角色讨论”“所有角色用中文” |
| `alaya-retrieval` | 总索引、类别索引、知识卡和交叉链接检索 | “查我的知识库”“结合知识库解释” |
| `alaya-import` | 批量导入、单篇收录、语义知识卡、质量检查 | “导入这些资料”“收录这篇文章”“整理成知识卡” |
| `alaya-memory` | 回答后固定提交、共享状态/历史、用户档案、BI 观察 | “记住这个偏好”“忘掉职业信息”“查看我的记忆” |
| `alaya-maintenance` | 动态索引、链接检查、90 天熏习、健康检查 | “检查知识库”“预览重建索引”“现在熏习” |

主技能只负责识别意图并路由。普通问答不自动启动 Alaya。

所有子技能共同遵守：

- 技能可更新，用户的 `alaya/wiki/raw` 不覆盖。
- `--kb-root` 指向知识库根目录，不指向技能目录。
- 写入前先完整验证；检查默认只读。
- 每次导入单独询问是否复制原文到 `raw/`。
- 每次角色回答和群组汇总完成后固定提交，使用唯一事件标识保证重试不重复。
- BI 观察位于 `alaya/bi_state.json` 与 `alaya/bi_notes.json`；共享角色记忆位于 `alaya/memory/shared/`，两者不能混用。
