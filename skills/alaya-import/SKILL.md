# Alaya 导入

## 先识别用户要哪一种

<!-- ALAYA_IMPORT_TRIGGERS -->
- “把这些资料导进知识库” -> 批量导入：保留源文件边界，适合多个文件
- “把这篇文章收录一下” -> 单篇收录：生成一张完整知识卡
- “帮我整理成知识卡” -> 语义整理：由当前智能体理解内容后生成卡片
<!-- ALAYA_IMPORT_TRIGGERS -->

用户说得不清楚时，只问一句：“你想按原文件批量导入、把单篇文章完整收录，还是让我理解后整理成知识卡？”

接着每次都问：“这次是否把原文复制到 `raw/`？”这是任务级选择，不能读配置替用户决定，也不能默认沿用上次答案。

若类别不明确，再用一句短问题确认类别。不得根据文件名静默猜一个新类别并发布。

## 三种方式

### 1. 批量导入

适合多个本地文件。先做零写入预览：

```bash
python scripts/batch_import.py <文件或目录> --category <类别> --copy-raw yes --dry-run --kb-root <目录>
```

用户确认后去掉 `--dry-run`。可加 `--parallel`，但并行只用于读取和提取；最终写卡片、原文和索引必须串行提交。

### 2. 单篇收录

先读取信息，确认标题、类别和原文策略：

```bash
python scripts/import_paper.py <文件> --mode info --kb-root <目录>
python scripts/import_paper.py <文件> --mode full --category <类别> --copy-raw no --kb-root <目录>
```

URL（网址）由宿主智能体先获取内容，再转为本地资料或语义知识卡；脚本不伪装联网下载能力。

### 3. 语义整理

当前智能体先理解内容，形成符合知识卡格式的 Markdown，再执行：

```bash
python scripts/post_process.py <知识卡.md> --category <类别> --copy-raw no --kb-root <目录> --dry-run
```

确认后去掉 `--dry-run`。脚本负责元数据、去重、路径安全和索引；内容理解由宿主智能体负责。

## 文件支持

- 核心支持：`.md`、`.txt`、`.rst`、`.py`、`.js`、`.ts`、`.json`、`.yaml`、`.yml` 等文本文件。
- PDF（便携文档格式）需要可选 `PyMuPDF（PDF解析库）`。缺少依赖时停止该文件，不得生成空卡或假装成功；向用户提供安装依赖、由宿主读取或稍后处理三个选择。
- 二进制或不支持格式列为阻塞项，其他可处理文件也不得在预览阶段写入。

## 去重和原文

- 卡片身份是“类别路径 + 文件名”，不能只按显示标题判断。
- 内容哈希相同视为重复，不再新增副本；同名但内容不同生成稳定后缀，不能覆盖旧卡。
- `--copy-raw yes` 时，卡片写 `source_file`，并复制到 `raw/`；目标同名冲突时按哈希判断重复或生成后缀。
- `--copy-raw no` 时，卡片写原始 `source_path`，不得制造不存在的 `raw` 链接。
- 原文复制后校验哈希；卡片和索引只在完整计划验证通过后提交。

## 导入完成后的固定反馈

1. 报告新增、重复、冲突改名、失败和索引状态。
2. 类别索引与总索引同步发布；总索引必须包含磁盘上全部有效类别，而不是只剩本次类别。
3. 每次提醒用户二选一：“现在让智能体更新类别描述，还是等待累计到阈值后再更新？”
4. 自动提醒阈值为类别内容发生变化后最多 3 天；达到自适应数量阈值也可提前提醒。普通类别不限制一次最多处理三个。
5. 顺带运行一次到期熏习检查：`python scripts/perfume.py --level 3 --kb-root <目录>`。

## 质量检查

```bash
python scripts/import_quality_review.py --category <类别> --kb-root <目录>
```

只统计严格知识卡，不把 `_category.md`、`README.md` 或总索引算入分母。空类别报告“无知识卡”，不得除零或虚构通过率。此命令默认只读；只有显式给 `--report-file` 才写报告。
